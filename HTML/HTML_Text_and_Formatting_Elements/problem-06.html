JAVA SCRIPT


JavaScriptis a programming language mainly used to make web pages interactive. It can be used to create buttons, animations, forms, and dynamic content.
It can be used for:
    > Creating interactive buttons and menus
    > Validating forms
    > Creating animations
    > Changing webpage content
    > Building web applications
    > Working with data and APIs

Important Concept: JavaScript can use variables to store information. And it can declare variables using let(changeable) or const(fixed).


        const name = "Divya";
        let age = 18;

        console.log("Hello!");
        console.log("My name is: "+ name);
        console.log("My age is: "+ age);

JAVA


Java is a powerful, object-oriented programming language used to build large-scale applications — from Android apps to enterprise software and banking systems.
Java follows the principle of "Write Once, Run Anywhere" because Java code runs on the Java Virtual Machine (JVM) on any platform.

Important Concept: Every Java program must have a class and a main method — public static void main(String[] args) — which is the entry point where execution begins.


        
        public class Main {

            public static void main(String[] args) {

                String name = "Divya";
                int age = 18;

                System.out.println("Hello, World!");
                System.out.println("Name: " + name);
                System.out.println("Age: " + age);
            }
        }
